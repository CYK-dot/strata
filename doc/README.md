# strata · 设计文档

这个目录承载 strata 的“为什么”和“契约”，与仓库根 `README.md` 的“怎么用”分开。

## 阅读顺序

1. [价值论证](value.md) — 为什么值得做。
2. [目标定义](goals.md) — 它是什么、不做什么、怎样算成功。
3. [规格与约束](spec.md) — 当前行为契约：TOML、求值、输出、API、诊断、能力与约束表。
4. [迭代设计](iterations/README.md) — 每个迭代一份设计记录；当前只有 `0001-dag-dependencies.md`。

## 维护规则

- `spec.md` 描述**当前**系统；行为变化时更新它。
- `iterations/NNNN-*.md` 是历史记录，不随后续迭代改写；新迭代另建文件。
- 仓库根 `README.md` 只讲怎么用；`doc/` 讲为什么、目标与契约。
- 文档里的“必须 / 不得 / 应当 / 可以”按 RFC 2119 理解。
